# Jiyeong Kim

Minimal academic homepage for GitHub Pages.

## Edit

- Update `index.html` with your bio, links, publications, experience, and awards.
- Replace `assets/profile-placeholder.svg` with a real profile photo.
- Add a CV PDF as `assets/Jiyeong_CV.pdf`, then update the CV link.

## Preview

Open `index.html` in a browser, or serve this directory locally with:

```sh
python3 -m http.server 8000
```
